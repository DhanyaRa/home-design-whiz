# DecorHub interior design experience

## Goal
Replace the starter page with a usable DecorHub experience for capturing a room, setting design preferences, and reviewing an adaptive room plan.

## Work
- Create a polished interior-design interface with warm neutral colors, distinctive typography, and room photography.
- Build a responsive guided flow for room details, lifestyle, design style, budget, and safety needs, with usable navigation and state.
- Add photo upload/capture and a clearly labeled scanning simulation with furniture detections and confidence values.
- Present an interactive plan view with a 2D furniture layout, recommended items and budget alternatives, safety suggestions, and report export/share actions.
- Add route-specific page metadata, update the design tokens, and verify the main flow and mobile layout.

## Technical details
- Keep the experience frontend-only with sample recommendations and local in-page state; no account, persistent storage, or actual AI/computer-vision processing is implied.
- Use existing project UI dependencies and TanStack Start conventions; keep the first experience at `/`.
